# Netflix on Fire OS 7 / ARM32: snapshot scanner

This addresses the synchronous memory-scan crash investigated in [#317](https://github.com/ajstrick81/morphe-androidtv-patches/issues/317). It does not change the ad anchors, the ad edits, the subscription, or the household settings.

## What changes

The scanner copies memory through `process_vm_readv` into one private buffer (256 KiB plus up to 4095 overlap bytes), then calls `Memory.scanSync` only on that copy. An unmapped or protected source becomes a kernel read error rather than a native fault inside Frida's exception recovery. Matches are translated back to the original addresses for the existing patch code.

Short reads are accumulated. Reads spanning a hole can fall back to one page so a readable prefix is retained. Overlap finds boundary matches once, and the scanner excludes its own buffer. An unavailable backend disables the scanner with one diagnostic instead of repeatedly allocating and retrying. There is no `/proc/self/mem` fallback, because that interface can bypass ordinary page protection.

A copied match records bytes observed at read time; it does not guarantee that the live destination will remain valid. The existing patch consumers and their checks are unchanged. The optional household async scanner's live-memory scanning is outside this fix; its match callback now filters out the snapshot buffer, with host regression coverage for inside-buffer and overlapping matches. The combined configuration was not device-tested.

Those final integration refinements, other devices, newer Netflix targets and the default Gadget engine have not been hardware-validated here.

## Build and install

1. Download the exact [Netflix Android TV 13.0.1 build 25028](https://www.apkmirror.com/apk/netflix-inc/netflix-android-tv/netflix-android-tv-13-0-1-build-25028-release/) `.apkm` bundle containing the ARM32 native split. Keep the original Netflix installation enabled.
2. Use a patch bundle built from this change. Until it is included in a release, an older published bundle does not contain this scanner. Build using the repository's normal workflow, or use the `.mpp` artifact from this PR's successful CI run.
3. In Morphe Manager, leave **Optimize for device architecture** off. Enable **Clone Netflix**, **Disable Netflix CertCheck**, both default **Remove Netflix ads** patches and **Remove Netflix ads (legacy engine)**. Leave optional household and fingerprint patches off for the tested configuration.
4. Alternatively, use Morphe Desktop 2.3.0 with Java 21+:

   ```bash
   java -jar morphe-desktop-2.3.0-all.jar patch \
     --patches patches-from-this-change.mpp --exclusive \
     -e 'Clone Netflix' \
     -e 'Disable Netflix CertCheck' \
     -e 'Remove Netflix ads (bundle engine)' \
     -e 'Remove Netflix ads (loader)' \
     -e 'Remove Netflix ads (legacy engine)' \
     --out netflix-clone.apk original-netflix.apkm
   ```

   Keep the signing key generated by the tool for subsequent updates. A different key cannot update an existing clone in place.
5. Enable ADB debugging on the Fire TV and connect from a computer on the same network. Confirm the debugging-key prompt on the TV:

   ```bash
   adb connect FIRE_TV_IP:5555
   adb devices -l
   adb -s FIRE_TV_IP:5555 install -r netflix-clone.apk
   adb -s FIRE_TV_IP:5555 shell am start \
     -n com.netflix.ninja.clone/com.netflix.ninja.MainActivity
   ```

6. Wake the TV before launching. Starting from its screensaver caused an unrelated background-service error in the initial test. Sign in to the clone on the TV; the original app stays installed. See [Amazon's ADB instructions](https://developer.amazon.com/docs/fire-tv/connecting-adb-to-device).

## Check the result

Watch the diagnostic tag, then play a title which previously showed ads:

```bash
adb -s FIRE_TV_IP:5555 logcat -v brief -s KILL
```

Expected evidence includes:

```text
snapshot-scan: backend=process_vm_readv; valid and invalid reads checked
PATCH V3-ADV: ... verify=OK
PATCH V3-MASTER: ... verify=OK
ANCHOR MAP: ... ADV=w ... MASTER=1w B=1 ...
```

An open app alone does not establish that ad removal is working. In the observed start, the first anchor summary at about 40 seconds still showed no applied hooks; successful hooks followed during the next minute. Some player code is loaded lazily during playback, so an initial pre-roll can still play before the hook lands. Retry the same title after the verification messages. Immediate ad-free playback after every cold start is not established by this test.

The device logged successful V3-ADV and V3-MASTER readbacks followed by `B=1`, and the user confirmed that the previously ad-interrupted playback worked. Pause-ad suppression was not separately visually tested. A 512 KiB native probe checked real byte contents, a copy-boundary match, original-address translation, an invalid address and a `PROT_NONE` middle page; it passed in 17 ms. The complete clone remained active through a 40-second startup observation and a further 45-second observation.

This is one-device evidence, not a long-duration or all-title guarantee. Netflix can change the downloaded player without an APK update. A missing anchor may therefore be a separate compatibility problem after the scanner itself is working.

## Host tests

No Netflix account, APK, ADB connection or Frida host installation is needed:

```bash
node --test testing/test_snapshot_scanner.cjs
node testing/test_killads_scheduler.js
```

The snapshot tests cover boundaries, wildcard matching, address translation, unreadable pages, partial and rejected reads, scratch exclusion, bounded allocation and initialization failure. The native probe and playback observations are additional manual hardware checks, not claims made by the Node tests.

## Revert

Open the original Netflix app, or remove only the clone:

```bash
adb -s FIRE_TV_IP:5555 uninstall com.netflix.ninja.clone
```

That removes the clone's local data, including its login. It does not remove the original app. The installed clone does not need a permanently connected computer; ADB can be switched off after testing.
